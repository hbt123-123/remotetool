# 常见问题（FAQ）

### 忘记 Web UI 的 token 了怎么办？

token 只在 rtd 启动时打印到控制台，不落日志。随时执行 `rt url` 重新
获取带 token 的地址。若把 rtd 配成了开机自启，登录后在终端跑即可。

### 端口被占了 / 想改端口？

`rtd --listen-port <QUIC端口> --web-port <UI端口>`。改了 QUIC 端口后，
其他设备配对/连接时要用新地址；防火墙放行也要对应改。

### Web UI 里的「局域网发现」是空的，是不是坏了？

不一定是故障。mDNS 在 Android（省电与多播限制）、跨网段、部分路由器
AP 隔离下不可靠。直接用对方 IP + 端口配对/连接即可
（见[配对指南](pairing-guide.md)）。

### 连接总是显示「经中继」？

双方 NAT 都是对称型（或防火墙阻 UDP）时直连会失败，自动经 hub 中继是
**预期行为**，不是故障；速度取决于 VPS 带宽。想让更多场景直连，
需要等 UDP 打洞功能（路线图）。

### 为什么不能把文件直接拖拽上传？

浏览器拖拽直传尚未实现（路线图），当前用文件面板的上传/下载按钮或
`rt cp`。

### 目录传输为什么取消不掉？

目录推送会拆成多个单文件传输，没有统一的传输 ID，因此不能按 ID 一键
取消；正在传的单个文件可以在传输列表里取消。

### 对方操作时我的设备会看到什么提示？

被拒绝的能力（终端/文件/转发被权限关闭、路径越界、目标不在白名单）
统一返回 `no such ...` 这类"不存在"话术——这是有意的（防探测），
真实原因看本机 rtd.log 与活动日志。

### 手机（Android）后台一会儿就断了？

Android 会冻结后台进程。三件套缺一不可：`termux-wake-lock`、电池
白名单、termux-services 常驻；公网场景务必给手机配 hub（网络切换后
自动重连）。详见 [android-setup.md](android-setup.md)。

### 想让对端访问我手机存储？

Termux 下默认授权目录是 app 私有目录。先 `termux-setup-storage`
授权，然后在设备详情页「权限 → 文件授权目录」改到
`~/storage/shared/...`。见 [android-setup.md](android-setup.md#已知边界)。

### 怎么查看版本？

`rt version`、`rtd -version`，或 Web UI「设置 → 关于」。发布产物
（tag 构建）的版本号与 tag 一致。

### 日志在哪？会无限变大吗？

`%APPDATA%\remotetool\rtd.log`（Windows）或 `~/.config/remotetool/rtd.log`
（Linux）。追加写入、无轮转，变大后可在 rtd 停止时手动删除，会自动
重建。详见[故障排查](troubleshooting.md)。

### 彻底卸载 / 重置本设备？

1. 停掉 rtd（并移除计划任务/systemd 服务）；
2. 删除配置目录：`%APPDATA%\remotetool`（Windows）或
   `~/.config/remotetool`（Linux）——identity.key、配对记录、日志全在里面，
   删除即重置设备身份；
3. 删除二进制文件。

### 删除配对后对方还能连我吗？

不能。删除配对后对方的连接会被当作未配对设备拒绝（需要重新配对才能
恢复）。对方设备上也会保留一条单向记录，建议双方都删一次，列表更干净。

### 两台设备必须同时在线吗？

配对时需要。日常使用：主控方发起连接，对端 rtd 在线即可（有 hub 时
双方各连各的 hub，不需要同网段同时发起）。终端会话断线会自动重连，
传输中断支持续传。

### 数据会经过你们的服务器吗？

不会。没有官方服务器：局域网直连；跨公网经**你自己部署**的 hub 中继，
且中继只见密文（见[安全说明](security.md#传输加密)）。
